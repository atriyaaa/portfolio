## 💻 Running Locally

Clone the repository:

```bash
git clone https://github.com/atriyaaa/portfolio.git
cd portfolio/my-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
